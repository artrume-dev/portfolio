Intro

The problem

Accessibility problems are easy to introduce and slow to find by hand. Teams need a repeatable way to test interfaces against WCAG and see what to fix.

Why it matters

Proof the factory ships

It shows the agent factory delivers usable software, not just demos.

Quality you can measure

Accessibility has a clear right answer, so the app's quality, and the factory's, can be measured instead of judged by eye.

Technical details

how it was built · how it's measured

This is internal enterprise work, so the implementation stays private. What I can share is how it was built and how its quality is measured.

How it was built

A11yCheck went through the full agent factory flow, from interview to shipped app.

  1. An agent interviewed me to pin down scope and hidden decisions.
  2. Domain context and a spec were written in a shared language.
  3. I approved the spec before any build started.
  4. The work was cut into vertical slices, each built test-first in its own worktree and checked end to end.
  5. A dual review checked standards and spec compliance; failures went back to the build loop.
  6. Releases were risk-tiered, with risky changes approved by me.
